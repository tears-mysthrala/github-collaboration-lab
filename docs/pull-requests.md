# Practicar pull requests y coautoria

1. Cree una rama con un cambio concreto y legible.
2. Compruebe el diff antes de abrir el pull request.
3. Indique el proposito y la validacion realizada.
4. Compruebe el autor, el destino y los conflictos antes de fusionar.
5. Verifique que el cambio aparece en la rama principal.

La atribucion de un commit puede incluir el trailer `Co-authored-by: Nombre <correo asociado a GitHub>`. Debe describir la participacion real; no equivale a una revision independiente.

En este laboratorio ambas identidades pertenecen a la misma persona y el contenido se prepara con asistencia de IA. Los ejercicios sin revision independiente son de documentacion y no deben trasladarse a cambios de produccion.

Referencias: https://docs.github.com/en/pull-requests y https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors
